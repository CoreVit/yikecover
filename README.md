# 一刻封面

一刻封面是一款面向 HarmonyOS 的轻量封面制作元服务。选择模板、替换图片与文字，即可生成适合内容发布场景的 16:9 封面。

## 主要功能

- 9 套代码封面模板与 1 套视频片尾模板
- 实时编辑品牌、标题、图片及模板专属内容
- 支持 720P、1080P、4K 导出
- 支持 PNG、JPEG 和 WebP，非 PNG 格式可调整清晰度
- 草稿、导出记录与偏好设置保存在本机
- 无需注册或登录

## 使用流程

1. 在制作页选择模板。
2. 替换图片、品牌和标题等内容。
3. 检查实时预览并调整模板选项。
4. 选择导出规格，将封面保存到系统相册。

## 运行环境

- HarmonyOS 6.1.0 或更高版本
- API 23 或更高版本
- 支持手机和平板设备
- 推荐使用 DevEco Studio 打开和构建

项目当前版本为 `1.0.0`。

## 本地开发

1. 使用 DevEco Studio 打开项目根目录。
2. 等待工程同步和依赖解析完成。
3. 在“项目结构 → 签名配置”中配置自己的调试签名。
4. 选择 `entry` 模块，在模拟器或真机上运行。

签名证书、密钥库、Profile 和本机配置不应提交到仓库。

## 数据与隐私

封面草稿、历史记录、上传图片副本和导出偏好均保存在当前设备。用户可在应用的“历史记录”页面清空本机数据。
