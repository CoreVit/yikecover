1. 服务提供者与服务内容

“一刻封面”由张佳宾（以下简称“我们”）提供。本元服务用于选择封面模板、编辑文字与图片、实时预览排版效果，并将生成的封面保存至系统相册。

我们可在保障核心功能和用户合法权益的前提下，对功能、界面或服务方式进行维护和改进。

2. 使用资格

您应当具有与使用本元服务行为相适应的民事行为能力。未成年人应当在父母或其他监护人的指导下阅读并使用本元服务。

3. 用户内容与使用规则

您主动选择的图片、输入的品牌名称、标题及其他文字内容由您自行负责。您应确保自己有权使用相关内容，并且不得利用本元服务制作、保存或传播违反法律法规、侵犯他人知识产权、肖像权、隐私权或其他合法权益的内容。

您不得通过逆向工程、恶意干扰、破坏服务运行或其他违法违规方式使用本元服务。

4. 本地数据与系统相册

本元服务不设置业务服务器。您主动选择的图片、输入的文字、草稿、导出记录及导出设置均在设备本地处理和保存，不会上传至开发者服务器。

为支持继续编辑，需要图片的模板可能会将您选择的图片副本保存在本元服务的应用私有目录，并随本地草稿保留。您可以在历史记录页面清空相关本地数据，也可以通过系统设置清除本元服务数据。

保存封面时，本元服务通过系统提供的保存界面，经您单次确认后将生成的图片保存至系统相册。已经保存至系统相册的图片独立保存在相册中，需要由您自行管理和删除。卸载本元服务通常会清除其内部数据，但不会自动删除已经保存至系统相册的图片。
