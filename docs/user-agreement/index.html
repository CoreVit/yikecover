4. 服务内容

一刻封面是我们通过HarmonyOS元服务为您提供的封面制作工具。您可以选择封面模板，编辑文字与图片，实时预览排版效果，并在确认后将生成的封面保存至系统相册。

一刻封面不提供账号登录、社交、广告、支付或个性化推荐服务。您主动选择的图片、输入的文字、草稿、导出记录及导出设置均在您的设备本地处理和保存，不会上传至开发者服务器。

5.3 请您结合自身实际需求，充分考虑模板样式、图片清晰度、文字内容及设备显示差异，确认并选择使用一刻封面服务。

5.5 为支持您继续编辑，需要图片的模板会将您主动选择的图片副本保存在一刻封面的应用私有目录，并随本地草稿保留。您可以在历史记录页面清空相关本地数据，也可以通过系统设置清除一刻封面数据。

5.6 当您主动保存封面时，一刻封面将通过系统提供的图片保存界面，经您单次确认后，将生成的图片保存至系统相册。已经保存至系统相册的图片需要由您在系统相册中自行管理和删除。
